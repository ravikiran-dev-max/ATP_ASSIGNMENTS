# Employees Pro - React Application

A modern **React.js** application for managing employees.  
This project demonstrates routing, form handling, CRUD operations, and styled UI components using **React Router**, **React Hook Form**, and **TailwindCSS**.

---

## 📦 Tech Stack
- **React.js** (functional components, hooks)
- **React Router v6** (routing and navigation)
- **React Hook Form** (form handling and validation)
- **Axios / Fetch API** (HTTP requests)
- **TailwindCSS** (styling)
