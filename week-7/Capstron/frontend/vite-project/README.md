# 🌐 CAPSTON

A complete **Blog Platform** built with **Node.js + Express + MongoDB** (backend) and **React + Vite + Bootstrap** (frontend).  
Supports **role-based authentication**, **image uploads via Cloudinary**, and a **responsive UI**.

---

## 📂 Project Structure

│── frontend/
│   ├── src/
│   │   ├── components/     # Reusable UI components
│   │   ├── styles/         #Common Styles
│   │   ├── apis/           # API calls (axios/fetch)
│   │   └── App.jsx         # Root component
│   └── vite.config.js      # Vite setup
│
│── .env                    # Environment variables
│── package.json            # Dependencies
