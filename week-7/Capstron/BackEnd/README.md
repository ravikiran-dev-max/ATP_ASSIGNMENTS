# 🌐 CAPSTON

A complete **Blog Platform** built with **Node.js + Express + MongoDB** (backend) and **React + Vite + Bootstrap** (frontend).  
Supports **role-based authentication**, **image uploads via Cloudinary**, and a **responsive UI**.

---

## 📂 Project Structure

project-root/
│── backend/
│   ├── APIs/               # Route handlers
│   ├── config/             # Cloudinary, Multer configs
│   ├── middlewares/        # JWT & role-based auth
│   ├── models/             # Mongoose models
│   └── server.js           # Entry point
