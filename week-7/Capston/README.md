# 🌐 CAPSTON

CAPSTON is a **Blog Platform** built with **Node.js + Express + MongoDB** (backend) and **React + Vite + Bootstrap** (frontend).  

It allows **Users** to read and comment on articles, while **Authors** can write, edit, and publish their own articles.  
An **Admin** manages both Users and Authors, ensuring smooth platform operations.

---

## ✨ Features

- Secure **User & Author Authentication**  
- Role-based access control (**User, Author, Admin**)  
- Users can **read and comment** on articles  
- Authors can **create, edit, delete, and re-upload** their own articles  
- Admin can **manage users and authors**  
- Deleted articles remain hidden until re-uploaded  
- Responsive UI with **TAILWINCSS** styling  

---

## 👤 User Guide

### Account Creation
- Select **User** role during registration.  
- Enter valid details and remember your password.  

### User Permissions
-  Read published articles  
-  Comment on articles  
-  Cannot view deleted articles until re-uploaded  

---

## Author Guide

### Account Creation
- Select **Author** role during registration.  
- Enter valid details and remember your password.  

### Author Permissions
-  Write and publish articles  
-  Edit own articles  
-  Delete and re-upload own articles  
-  Cannot edit or read other authors’ articles  

---

##  Admin Role

- Manage **Users** and **Authors**  
- Control **account status** (activate/deactivate)  
- Moderate **articles** across the platform  

---

##  Tech Stack

- **Backend**: Node.js, Express, MongoDB  
- **Frontend**: React, Vite, Bootstrap  
- **Authentication**: JWT & bcrypt  
- **Database**: MongoDB Atlas
