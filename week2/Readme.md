# JavaScript Practice Examples

This repository contains modular JavaScript examples demonstrating **core concepts** such as functions, destructuring, error handling, promises, shallow vs deep copy, object manipulation, callbacks, optional chaining, and array methods.

---

## File Structure

- `CustomCalculationFunctions.js` → Arithmetic functions (addition, subtraction, multiplication, division, percentage).
- `DestructuringArray.js` → Array and object destructuring.
- `ErrorHandling.js` → Try/catch error handling.
- `shallowCopy.js` → Shallow copy of arrays using spread operator.
- `ModuleExport.js` → ES6 default export example.
- `ModuleImport.js` → Import example (`import a from './module1.js'`).
- `promise.js` → Promise with resolve/reject after delay.
- `promiseCall.js` → Promise with async delay and proper `.then/.catch`.
- `RestParameter.js` → Rest parameters with `reduce()` to sum arguments.
- `asyncchronousSimulation.js` → Asynchronous execution with `setTimeout`.
- `objectCopy.js` → Shallow vs deep copy of objects.
- `objectManipulation.js` → Object property operations and callback function example.
- `optionalChaining.js` → Optional chaining (`?.`) and nullish coalescing (`??`).
- `ArrayMethods.js` → Demonstration of JavaScript array methods (`filter`, `map`, `reduce`, `find`, `findIndex`, `sort`).
-`salaryProcessingExample.js` → HR salary module using array methods.
- `bookLibraryExample.js` → Book class with borrow/return logic and availability checks.
- `moviesExample.js` → Movie dataset processed with array methods.
- `otpSimulation.js` → OTP generation and resend simulation using `setTimeout` and `setInterval`.
-`shoppingCartExample.js` → Shopping cart simulation for an e‑commerce website.

---

## Concepts Covered

### 1. Functions
- Arithmetic functions and rest parameters.

### 2. Destructuring
- Array and object destructuring.

### 3. Error Handling
- `try/catch` with error messages.

### 4. Shallow vs Deep Copy
- Spread operator vs `structuredClone`.

### 5. ES6 Modules
- Default export and import usage.

### 6. Promises
- `.then()` and `.catch()` with async simulation.

### 7. Asynchronous Execution
- `setTimeout` scheduling.

### 8. Object Manipulation
- Add, update, delete properties.

### 9. Callbacks
- Passing functions as arguments.

### 10. Optional Chaining & Nullish Coalescing
- Safe property access with defaults.

### 11. Array Methods
- **filter** → select elements by condition.
- **map** → modify elements.
- **reduce** → aggregate values (min, max, sum, average).
- **find** → locate specific element.
- **findIndex** → locate index of element.
- **sort** → ascending/descending order.
- Examples include numbers, temperatures, and arrays of objects (students with marks).

### Classes
- Book class with borrow/return methods.
- Library simulation with availability checks and long book counter.
