# HTML Examples Project

This repository contains simple HTML examples with comments to illustrate basic web page structures and elements.

---

## Example 1: Basic Page with Headings, Paragraphs, and Lists
**File:** `UnorederedList.html`

### Features:
- `<p>`: Paragraphs with placeholder text.
- `<h1>`: Main heading.
- `<ul>`: Unordered list of fruits.
- Comments included to explain each section.

This example demonstrates how to structure text content and lists in a webpage.

---

## Example 2: Pochi The Cat Profile Page
**File:** `PochiTheCat.html`

### Features:
- `<h1>` and `<h2>`: Headings for sections (*Introduction*, *Profile*, *Links*).
- `<img>`: Image aligned to the right with width specified.
- `<p>`: Multiple paragraphs for description and profile details.
- `<ul>`: List of external links.
- `<hr>`: Horizontal rule for separation.

This example shows how to build a simple profile page with text, images, and links.

---

## Example 3: Nested Lists
**File:** `NestedUnorderedList.html`

### Features:
- `<ul>`: Unordered list with categories (*Fruits*, *Vegetables*, *Cereals*, *Nuts*).
- Nested `<ul>` inside list items to show subcategories (e.g., types of fruits and vegetables).
- Comments explain the nesting structure.

This example demonstrates how to create hierarchical lists in HTML.

---

##  How to Use
1. Open any `.html` file in a web browser.
2. Observe the structure and layout.
3. Modify text, images, or lists to experiment with HTML basics.

---

## Learning Notes
- Always include `<!DOCTYPE html>` at the top of your HTML files.
- Use comments (`<!-- -->`) to explain sections of your code.
- Nest lists carefully to maintain readability.
- Use semantic tags (`<h1>`, `<h2>`, `<p>`, `<ul>`) for clear structure.
