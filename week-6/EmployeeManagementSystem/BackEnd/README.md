# Employee Management API

A RESTful API built with **Express.js** and **Mongoose** to manage employee records.  
Supports full CRUD operations: Create, Read, Update, and Delete employees.

---

## 📦 Tech Stack
- **Node.js** with Express.js
- **MongoDB** with Mongoose ODM
- REST API architecture
